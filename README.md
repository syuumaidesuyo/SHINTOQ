# SHINTOQ

長野県と東京をつなぎ、人や地域、アイデアの新しい接点をつくるSHINTOQの紹介サイトです。活動内容・理念・イベントのお知らせ・参加者募集を1ページで案内します。

## 表示する

`index.html` をブラウザーで開くと表示できます。GitHub Codespacesなどからプレビューする場合は、PowerShellで `.\serve.ps1` を実行し、ポート8000を開いてください。ビルドや外部ライブラリは不要です。

## 内容を編集する

掲載内容は `content.js` にまとめています。紹介文、活動、活動履歴、理念、イベント、問い合わせ先を編集してください。開催日時や会場、募集状況、問い合わせ方法などの情報は、公開前に実際の内容に更新してください。

公式Instagramの紹介文・アカウント名・URLも `content.js` の `instagram` で編集できます。

## 画像を追加する

1. 画像ファイルを `assets/images/` に置きます。
2. `content.js` 内の画像パスを `assets/images/ファイル名.jpg` のように設定します。

SVG、PNG、JPEG、WebPなどのブラウザーで表示できる形式を使えます。ヒーロー画像は `hero.image`、理念画像は `philosophy.image`、イベント画像は各 `events.items` 項目の `image` で指定します。ロゴはヘッダーとフッター共通で `assets/images/shintoq-logo-black.png` を差し替えます。

イベントや活動紹介に掲載している写真にはイメージ写真が含まれます。イベント写真の出典とライセンスは各イベント欄に表示しています。活動履歴の項目・写真は `content.js` の `activityHistory` で編集できます。

## 公開前の設定

- `content.js` の活動・イベント・募集内容を最新情報に更新する
- 実際のロゴ、写真、問い合わせ先やSNSリンクが決まったら追加する
- 日付、開催場所、申込方法など参加に必要な情報をイベントごとに記載する
